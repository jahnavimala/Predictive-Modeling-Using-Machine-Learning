# Predictive-Modeling-Using-Machine-Learning
# Heart Disease Prediction

A machine learning project that predicts whether a patient has heart disease using classification algorithms.

---

## Project Overview

This project applies supervised machine learning techniques to predict heart disease.

The model learns from patient medical records and predicts whether heart disease is present.

---

## Dataset

Source:

Heart Disease Dataset from Kaggle

Target Variable:

- `target`
  - 0 = No Disease
  - 1 = Disease

---

## Features Used

- Age
- Sex
- Chest Pain Type
- Blood Pressure
- Cholesterol
- Blood Sugar
- Heart Rate

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Machine Learning Workflow

### 1. Data Collection
Downloaded dataset from Kaggle.

### 2. Data Cleaning
Performed:
- Missing value handling
- Duplicate removal
- Feature selection

### 3. Model Training
Applied:
- Decision Tree
- Random Forest

### 4. Model Evaluation
Measured:
- Accuracy Score
- Confusion Matrix
- Classification Report
